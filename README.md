## Project at a glance

| Thành phần | Quyết định hiện tại |
|---|---|
| Target user | Sinh viên tài chính và nhà đầu tư cá nhân giai đoạn đầu đã có danh mục đa tài sản |
| User task | Đánh giá có nên giữ nguyên, tái phân bổ hoặc phòng hộ danh mục |
| Product | Web dashboard phân tích attribution và rủi ro danh mục |
| Main output | Portfolio Attribution & Risk Report |
| Core process | Calculate → Attribute → Compare/Simulate → Explain |
| MVP principle | Một luồng hoàn chỉnh, giải thích được và kiểm thử được từ portfolio input đến quyết định |

## Responsible use of AI

AI được sử dụng để hỗ trợ tổ chức và biên tập tài liệu theo rubric Week 1–2. Nhóm chịu trách nhiệm kiểm tra mọi giả định, công thức, nguồn dữ liệu và tuyên bố về người dùng. Chỉ artefact thực sự có trong repository mới được xem là evidence chính thức.
