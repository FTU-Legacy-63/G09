# Decision and Revision Log

Tài liệu này lưu quyết định sau feedback để thể hiện chu trình PBL: **Evidence → Feedback → Revision**.

## Checkpoint 1

| Field | Record |
|---|---|
| Evidence reviewed | Problem candidates, selected user, user task, draft problem statement và initial responsibility table |
| Feedback received | Các vai trò cần rõ hơn và khối lượng công việc cần được phân chia hợp lý hơn giữa các thành viên. |
| Decision | **Change** |
| Revision made | Chuyển từ role title chung sang responsibility by output; mỗi thành viên có visible output và consumer/dependency cụ thể. |
| Repository evidence | [TEAM_RESPONSIBILITIES.md](TEAM_RESPONSIBILITIES.md) |
| Remaining question | Cần bổ sung issue/commit/file link cho từng output khi artefact được đưa lên repository. |

## Checkpoint 2

| Field | Record |
|---|---|
| Evidence reviewed | [PROJECT_PROPOSAL.md](PROJECT_PROPOSAL.md) và [SOLUTION_STRUCTURE.md](SOLUTION_STRUCTURE.md) |
| Feedback received | _Chưa cập nhật_ |
| Decision | _Keep / Change / Simplify / Restart_ |
| Revision made | _Chưa cập nhật_ |
| Reason | _Chưa cập nhật_ |
| Remaining question | _Chưa cập nhật_ |

## Revision rule

Mỗi checkpoint mới phải ghi rõ:

1. giảng viên hoặc reviewer đã hỏi/challenge điều gì;
2. nhóm quyết định Keep, Change, Simplify hay Restart;
3. file hoặc artefact nào đã thay đổi;
4. tại sao thay đổi đó làm solution chain rõ hoặc khả thi hơn.
